# The 30-Day Action Plan

The whole course compressed into a day-by-day schedule. Students who follow this end
day 30 with: positioning set, an offer validated, a media kit live, 20 brand pitches
sent, a lead magnet capturing emails, and their first launch scheduled or done.

Print it. Check the boxes.

> ✏️ **FILL IN:** Adjust day counts to match your final lesson lineup, and record a
> short "here's your next 30 days" walkthrough video to sit alongside this document.
> If you run cohorts or the coaching tier, align these weeks to your call schedule.

---

## Week 1 — Foundations (Module 1 + 2)

- [ ] **Day 1:** Watch Module 1. Write 90-day goal + 1% math.
- [ ] **Day 2:** Draft 5 positioning statements; send top 2 to three warm followers.
- [ ] **Day 3:** Full brand audit (profile, last 30 posts G/T/S, audience, assets).
- [ ] **Day 4:** Update bio + pinned content to match chosen positioning.
- [ ] **Day 5:** Watch Module 2. Choose your ONE path. Draft offer one-pager.
- [ ] **Day 6:** Post the validation post. DM your 20 warmest followers.
- [ ] **Day 7:** Weekly review #1 (Module 7.2 format). Log validation replies.

## Week 2 — Content engine + brand-deal assets (Modules 3 + 4)

- [ ] **Day 8:** Watch Module 3. Start idea bank (20 entries from DMs/comments).
- [ ] **Day 9:** Write the week's content: 3 Growth, 3 Trust, 1 Sales post.
- [ ] **Day 10:** First batch-record session. Schedule the week.
- [ ] **Day 11:** Watch Module 4.1–4.2. Build media kit from template.
- [ ] **Day 12:** Build rate card (with usage-rights pricing).
- [ ] **Day 13:** Build the 50-brand target list.
- [ ] **Day 14:** Weekly review #2. Finalize kit + list.

## Week 3 — Pipeline + funnel (Modules 4 + 5)

- [ ] **Day 15:** Send brand pitches 1–10. Set day-4/day-10 follow-up reminders.
- [ ] **Day 16:** Batch session #2 (this repeats weekly forever — it's the engine).
- [ ] **Day 17:** Watch Module 5. Outline lead magnet.
- [ ] **Day 18:** Build lead magnet + capture page (one sitting, max 3 hrs).
- [ ] **Day 19:** Send brand pitches 11–20. Follow-ups for days 15's batch queue up.
- [ ] **Day 20:** Post first "comment [WORD]" post → run the DM flow on every reply.
- [ ] **Day 21:** Weekly review #3. Pipeline check: pitches sent, replies, captures.

## Week 4 — Sales page + launch (Modules 5, 6, 8)

- [ ] **Day 22:** Draft sales page (8 sections, ugly v1).
- [ ] **Day 23:** Batch session #3. Ship the sales page.
- [ ] **Day 24:** Watch Module 6 if high-ticket: set up booking link + call scripts.
- [ ] **Day 25:** Watch Module 8: write disclosure lines, audit old posts, book
      accountant consult.
- [ ] **Day 26:** Plan the 7-day launch calendar with real dates.
- [ ] **Day 27:** Launch day 1–2 content (seed posts) goes live.
- [ ] **Day 28:** Weekly review #4 + full month retro: pitches out, replies, emails
      captured, sales. Compare against Day 1's 90-day goal.
- [ ] **Days 29–30:** Launch continues (open + proof days). Keep working the DMs.

---

## After day 30 — the repeating rhythm

Weekly, forever: one batch session, one weekly review, 5–10 new brand pitches while
you want deal flow, every "comment [WORD]" reply worked through the DM flow. Quarterly:
one scaling lever (Module 7.4).
